In addition to the core project implementation, this repository includes an educational folder. The goal of this folder is to provide clear, step-by-step explanations of how different parts of the project work under the hood.

This serves two main purposes:

Learning Resource – It breaks down technical concepts and implementation details in a way that contributors or anyone new to the project can easily follow. Instead of only seeing finished code, readers can understand the “why” and “how” behind the design choices.

Documentation of Thought Process – Beyond just the final solution, the folder captures the reasoning, intermediate steps, and trade-offs made during development.

Topics include:

Explanations of architecture

Walkthroughs of core modules and their interactions

Example inputs/outputs and how they are processed
